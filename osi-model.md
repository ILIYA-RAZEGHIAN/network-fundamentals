
hi today I learned about OSI layer and TCP/IP
1- OSI = Open System Interconnection
2- it has 7 layers
-Application layer is the layer that creates a request for socket and starts protocol stack
-Presentation layer is encryption system
-Session is the layer that holds the connection and you don't need to log in many times
-Transport layer is the layer that uses UDP or TCP to send data payload
-Network is the layer that chooses the path of packet
you can see the path with use ctrl + n then type cmd and print route
-Data Link is the layer that chooses your MAC and fixes the frame
-and the Physical layer is the layer that goes with a cable to send data
-----
TCP/IP is really a layer that creates and uses
you can see the layers very well in Wireshark
1- First of all Application layer is same as OSI layers 5 to 7
2- Transport layer is same as OSI layer 4
3- Internet layer is same as OSI layer 3
4- Network Access layer is same as OSI layers 1 and 2
